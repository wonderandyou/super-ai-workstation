【怎么装】

  1. 把压缩包整个解压到一个文件夹里
     （别在压缩包里直接双击，会失败）

  2. 双击「安装.vbs」

  3. 按向导点几下：选个安装位置 → 下一步 → 完成
     装完桌面上会多一个「超级AI工作台」的图标

  4. 以后双击桌面图标就能打开（不会弹黑框）


【装之前需要什么】

  · Windows 10 / 11
  · Python 3.10 或更高（python.org 下载，装的时候
    **一定要勾上 “Add Python to PATH”**）
  · 硬盘留几 GB 空间


【装完能干什么】

  界面、设置、作品库这些**立刻就能用**，一行代码不用配。

  要跑 AI 功能的话，去对应页面点「⬇ 一键下载」：
    🐋 本地千问生图   需要独立显卡（显存 8 GB 起）
    🎨 AI 溶图        方案 A 纯 CPU 就能跑
    🎚️ AI 人声分离    独立显卡
    ✂️ AI 抠图        核显就够
    📖 声音包朗读     独立显卡
    🎵 AI 音乐工坊 / 🎤 AI 翻唱   模型要自己另想办法（见界面提示）
    🎨 豆包生图 / 🔍 AI 搜索      云端功能，要填 API Key

  打开界面后，第一屏的「开场提示」会把这些说清楚。


【会花钱的地方】（就这几处）

  · 豆包 Seedream 生图  —— 云端按张收费
  · AI 搜索引擎         —— 云端按字数收费
  · 高速工作流          —— 云端按字数收费
  其余功能都在你自己电脑上跑，不花钱、不上传。


【需要实名认证的地方】

  · 火山方舟（豆包生图）
  · DeepSeek 开放平台（AI 搜索、高速工作流）
  本地功能一个都不需要。


【怎么卸载】

  把安装目录整个删掉，再删掉桌面快捷方式就行。
  不写注册表、不留后台服务。


【出问题了】

  常见情况：
  · 双击没反应      → 多半是没装 Python，或装的时候
                      没勾 “Add Python to PATH”
  · 桌面图标打不开  → 安装目录被挪走或删了，重装一次
  · 模型下不动      → 看页面上的提示，官方源连不上时会
                      如实告诉你，不会偷偷换源
