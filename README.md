# 超级AI工作台 · Super AI Workstation

> **一切奇迹的起点** —— 本地 + 云端一体化的 AI 工具箱，一个网页界面搞定十几种 AI 活。

📖 **完整介绍** → [超级AI工作台-介绍.md](介绍.md)（功能全览 · **模型出处** · 配置要求 · 常见问题）

把「生图 / 生视频 / 写歌 / 翻唱 / 配音 / 抠图 / 溶图 / Live2D 制作」这些 AI 能力，
收进一个本地网页工作台：双击启动，浏览器打开就能用。

- **能本地的就本地跑** —— 用你自己的显卡，不联网、不花钱、不上传
- **要算力的走云端** —— 接官方 API（火山方舟 / DeepSeek / 智谱），按量计费
- **免安装** —— 自带 Python 运行时，解压双击即用，不用装环境

### 🎭 Live2D 制作

把一张动漫立绘变成会**眨眼、呼吸、转头、头发摆动**的 Live2D 模型（`.moc3`）：
AI 自动拆成头发/脸/眼睛等图层 → 自动绑定骨架与动作 → 导出即可用
（能当虚拟形象、桌面挂件）。

两种拆层方式：**本地引擎**（用自己显卡，不联网）/ **在线官方演示**（作者云端，免费但要排队）。

## 快速开始

### 方式一：下载即用（推荐）

到 [Releases](../../releases) 下载 **`SuperAI-Workstation-v1.3-portable.zip`**：

1. **整个解压**到任意文件夹（别只解一部分）
2. 双击 **`启动.vbs`**（首次会顺手在桌面建快捷方式）
3. 浏览器自动打开工作台

> 自带 Python 运行时，**不用预装任何环境**。

### 方式二：从源码跑

需要 **Python 3.11**：

```bash
python app.py
```

然后打开 <http://127.0.0.1:8200>

> 部分功能依赖第三方环境（ComfyUI / F5-TTS / Seed-VC / See-Through 等），
> 工作台里「⚙️ 设置 → 本地模型 / 运行环境」有一键安装入口。

## 模型从哪来

工作台里 **设置 → 📦 本地模型** 有分组的一键下载，全部走**正规官方渠道**并**逐个校验哈希**：

- **ModelScope**（阿里官方）
- **厂商官方 CDN**（Meta / NVIDIA / PyTorch）
- **官方 GitHub Releases**

> 口径：只用官方直连或厂商/高校官方平台；下完逐字节比对官方哈希，对不上就删掉不用。

---

## 会花钱的地方（只有三处）

- **豆包 Seedream 生图** —— 火山方舟云端，按张计费
- **AI 搜索引擎** —— DeepSeek 接口，按 token 计费
- **高速工作流** —— 同样是 DeepSeek 接口，按 token 计费

其余功能全在**你自己的电脑上**跑：不花钱、不上传、断网也能用。

## 需要实名认证的地方（同样只有三处）

**火山方舟** / **DeepSeek 开放平台** / **智谱开放平台** —— 都是可选的云端 API。
本机功能**不需要任何实名认证**。

## 算力要求

| 档位 | 能跑什么 |
|---|---|
| 🟢 只要能联网 | 豆包生图、AI 搜索、高速工作流、AI 生视频、Live2D 在线演示 |
| 🔵 纯 CPU 就行 | AI 溶图 · 方案 A |
| 🟡 核显够用 | AI 抠图 |
| 🟠 独显 ≥ 6 GB | AI 人声分离、声音包朗读 |
| 🔴 独显 ≥ 8 GB | 本地千问生图、音乐工坊、溶图方案 B、翻唱、Live2D 本地引擎 |

**内存建议 16 GB 以上**。后端都是**按需启动**的 —— 别同时全开，容易挤爆内存。

```
启动.vbs / 启动.cmd   启动入口
安装向导.py           tkinter 安装向导（给不熟电脑的人用）
```
