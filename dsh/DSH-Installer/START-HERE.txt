DSH 一键安装包 · 先看这个
================================================================

第 0 步（很重要，先做）
  先把 zip 完整解压成一个文件夹，不要在压缩包里直接双击运行。
  如果右键 zip →「属性」里有「解除锁定 / Unblock」选项，勾选后再解压。

第 1 步  双击  Install-DSH.cmd
  · 打开后会先弹出「DeepSeek API 密钥购买提示」（5 步流程，约 2 分钟）
  · 界面上选安装方式：
        标准安装 MSI  → 需要管理员权限，会弹 UAC 授权，点“是”
        便携安装 ZIP  → 完全不需要管理员权限
  · 点右下角「开始安装」，等进度条走完（一般 2~6 分钟，看网速）

第 2 步  点「启动 DSH Web」，或双击桌面上的「DSH Web」快捷方式
  · 浏览器会自动打开带授权令牌的地址（手动输 http://127.0.0.1:3080 打不开，
    必须用自动打开的那个地址）
  · 首次使用：在网页里打开「设置 → 模型（Models）」，粘贴你的 sk- 密钥

还没有密钥？打开 https://platform.deepseek.com/
  登录（手机号验证码 / 微信扫码）
    → 左侧「充值」→ 选金额 → 支付宝或微信付款
    → 左侧「API keys」→ 右上角「创建 API key」
    → 复制 sk- 开头的那串字符（关掉弹窗后就再也看不到了，先存好）
  提示：网页版聊天是免费的，这里的余额只给 API/DSH 用。

出问题看哪里
  · 安装日志：%LOCALAPPDATA%\DSH-Installer\install-*.log
  · 环境自检：右键 Check-DSH.ps1 →「使用 PowerShell 运行」
  · 全局 dsh 命令不好使：双击 launcher\dsh-web-npx.cmd（官方 npx 方式启动）
  · 全中文详细说明（含常见问题、卸载方法）：同目录 README.md

Windows 提示「Windows 已保护你的电脑」时：点「更多信息」→「仍要运行」。
从微信/QQ 收到的包，解压前先右键 zip →「属性」勾选「解除锁定」更稳。

安装脚本只做三件事：下载安装官方 Node.js → 执行
npm install -g @deepseek-ai/dsh → 在 DSH 包里注入 dsh web 启动器。
不会上传任何数据，密钥只写在本机。

（补充：@deepseek-ai/dsh 是 DeepSeek 官方包；官方文档推荐的启动写法是
 npx @deepseek-ai/dsh web，本包用的是把它全局安装后用 dsh web，效果等价。）
