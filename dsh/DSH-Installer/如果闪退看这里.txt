安装失败 / 点开就退出？先看这里
============================================================

【最快办法】直接双击命令行版，绕开图形界面
------------------------------------------------------------
    Install-console.cmd

它完全不加载图形界面（所以不会因为界面问题失败），而且用便携模式，
不需要管理员权限、不会弹 UAC。过程全部打在黑窗口里，装完会停住。

如果连它也不行，请把下面两个文件发给开发者：
    %TEMP%\DSH-install-boot.log
    %TEMP%\DSH-install-output.log


【两个启动器的区别】
------------------------------------------------------------
  Install-DSH.cmd       正常版，有图形界面（好看）
  Install-console.cmd   命令行版，没有界面，但最稳


【想自己查原因】
------------------------------------------------------------
第 1 步  Win+R 粘贴：%TEMP%\DSH-install-boot.log

   · 文件不存在  ->  .cmd 根本没被执行
                     原因：杀毒软件拦截，或双击错了文件
   · 文件存在    ->  引导器跑过了，继续第 2 步

第 2 步  Win+R 粘贴：%TEMP%\DSH-install-output.log
         里面是 PowerShell 的完整报错。

第 3 步  完整安装日志在：%LOCALAPPDATA%\DSH-Installer\install-*.log


【常见原因】
------------------------------------------------------------
1. 在压缩包里直接双击运行
   -> 必须：右键 zip -> 全部解压缩，进文件夹再运行

2. 杀毒软件拦截（火绒 / 360 / Windows Defender）
   -> 临时退出杀软再试。脚本要下载 Node 并跑 npm，容易被拦。

3. 只把 .cmd 单独拷出来了
   -> 它必须和 Install-DSH.ps1 在同一个文件夹里。

4. 双击的是 Install-DSH.ps1
   -> 双击 .ps1 会退出。请双击 .cmd。


【正常应该看到什么】
------------------------------------------------------------
双击 Install-DSH.cmd 后会出现一个黑窗口：

    DSH Installer  -  bootstrap
    Folder : ...\DSH-Installer\
    [1/4] checking PowerShell ...
    [2/4] collecting environment info ...
    [3/4] clearing the downloaded-from-internet lock ...
    [4/4] starting the installer, please wait ...

然后图形安装界面出现。如果图形界面起不来，现在会自动改成命令行
模式继续安装，并把错误打在黑窗口里（窗口会停住不会闪退）。
